# Contributing

This repository is a portfolio write-up of a completed applied-AI research project (the Bank Rage Analyzer). It is documentation plus a supporting taxonomy, not an actively maintained software package — see [REPRODUCIBILITY.md](REPRODUCIBILITY.md) for what is and isn't included.

If you have a correction, a question, or want to discuss the build-vs-buy methodology, the best path is to open a GitHub issue or reach out directly:

- **Email**: tejaswar.padala@gmail.com
- **LinkedIn**: https://www.linkedin.com/in/teja-padala/

## Suggested discussion topics

- The build-vs-buy framing and where the specialist's macro-F1 advantage comes from
- The labeling methodology and inter-rater reliability approach
- What the expanded follow-on research phase should prioritize (larger-scale benchmarking, expanded human validation, broader model coverage)
